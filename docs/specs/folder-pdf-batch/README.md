## 复现静态校验

在本目录运行：

```bash
python supporting/validate_spec.py
```

提供sha256sum的环境还可执行：

```bash
sha256sum -c supporting/checksums.sha256
```

这些检查只验证规格及其索引，不验证PDF功能或CDE符合性。实际实施从M0的仓库基线复核开始，先交付M1的文件夹自动处理路径；导航、OCR和字体随后按任务依赖并行推进。
