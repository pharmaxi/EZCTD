## 优先探针

### A. Inherit Zoom：6.8 / 6.15

比较`/XYZ ... null`、`/XYZ ... 0`、`/Fit`、显式zoom=1.0以及命名目的地。该组可以最小成本确定官方验证器是否按PDF语义解析，还是做字面结构检查。

### B. 注释与电子签章：6.18

比较Link、Text、Highlight、普通Widget、签名Widget和CDE签章软件生成文件。该组决定注释检测器是否必须识别签章上下文，优先级最高。

### C. 安全设置与密码：6.19 / 6.21

比较未加密、空用户密码+owner限制、加密但权限全开、非空用户密码和DocMDP。目标是拆清‘能打开’与‘受限’两个官方规则。

### D. 大于5页书签：6.23

比较5页无书签、6页无书签、6页有效书签、空Outlines、仅失效书签和豁免节点，确定边界及规则联动。

## 规则交互原则

官方验证器可能对同一对象输出多个finding，也可能通过先决条件抑制下游规则。EZCTD初期不应主动模仿未知的抑制逻辑；应先保留所有独立证据，再用官方黑盒结果决定展示去重。
